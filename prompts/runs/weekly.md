# Weekly run (Saturday, 06:46 IST)

Follow `prompts/runs/_git.md` for setup, validation and commit. Then:

1. `python scripts/dsys.py period` gives `this_week` (ending tomorrow) and `next_week` (the week to plan).
2. **Feedback for `this_week`**: if `inbox/feedback.md` has content, follow `prompts/feedback.md` for period `this_week` (and older periods if the feedback refers to them). If no feedback was given, do nothing: unmentioned items expire quietly. Do not invent feedback.
3. Inbox ideas: `prompts/inbox.md`.
4. Plan `next_week`: follow `prompts/weekly.md`.
5. **Papers of the week (required):** create next week's list with at least 3 entries, following `prompts/reading_list.md`. The daily runs add to it during the week.
6. Validate, commit `weekly: <next_week>`, push.
7. Final message: the items grouped by part (Papers of the week, Research, Knowledge by subject, Exploration, Languages), titles only; then one line saying they can reply in `inbox/feedback.md` or a Claude chat, or ignore it.
